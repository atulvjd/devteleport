03 / GET RUNNING

Your startup guide

Credentials and system tools are configured separately. Startup commands run in your terminal; DevTeleport does not start a server automatically.

Your encrypted snapshots.

Uses the selected capture destination folder. Display labels are stored locally and never alter archive contents.

Select a destination folder in Capture, then refresh the library.
Local-network transfer · experimental until physical two-Mac validation.
TLS 1.3, explicit receiving approval, certificate-based pairing and SHA-256 verification. No cloud relay or remote command execution. Share the protected pairing descriptor out of band and compare the fingerprint. Never disable the firewall.

Receive on this Mac

For another Mac, bind to this Mac’s LAN IP or 0.0.0.0 and enter a reachable advertised address. Default 127.0.0.1 is for same-Mac tests only. Resume requires a new pairing descriptor.

Send from this Mac

No receiver identity has been loaded.

Appearance & preferences.

Encryption is always enabled. Database and Docker connections use explicit project configuration and protected environment variables, not stored passwords.

Tools, without assumptions.

Homebrew, PATH and common version managers are discovered. No software is installed automatically. Paths can contain spaces and Unicode.
