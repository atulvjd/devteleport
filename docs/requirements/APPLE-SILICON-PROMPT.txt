# 7. SECURE MAC-TO-MAC TRANSFER

Implement a functional local-network transfer feature.

Goal:

A developer should be able to transfer a snapshot between two Macs without using a USB drive or manually uploading the archive.

Desired commands:

```bash
devteleport send snapshot.dtp
```

```bash
devteleport receive
```

Desktop experience:

- Send snapshot.
- Discover or enter destination Mac.
- Pair devices.
- Review destination identity.
- Confirm transfer.
- Show progress.
- Verify completion.
- Offer restore.

Security requirements:

- Encrypted transport.
- Authenticated device pairing.
- Explicit receiving-device approval.
- No unauthenticated network receiver.
- No remote command execution.
- Integrity verification.
- Connection failure handling.
- Interrupted transfer recovery.
- Transfer resume when supported.
- Clear timeout behavior.
- Safe temporary-file handling.
- No cloud requirement.

Prefer established, audited cryptographic protocols instead of designing custom cryptography.

Local-network discovery may use Bonjour/mDNS where appropriate.

Support manual address-based pairing if discovery fails.

Do not require users to disable the macOS firewall.

If transfer cannot be proven reliable, preserve the functional file-based workflow and mark network transfer experimental.
