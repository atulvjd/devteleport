## ROLE

You are an elite principal software engineer, systems architect, security engineer, DevOps engineer, QA automation engineer, and developer-tool product designer.

You are responsible for designing, implementing, integrating, testing, documenting, and preparing a complete, fully functional open-source developer application called **DevTeleport**.

Do not create a proof of concept, visual mockup, placeholder product, or incomplete scaffold.

Build actual working software.

Your goal is to allow a programmer to capture their current local development workspace on Computer A, transfer it to Computer B, and restore that workspace so they can continue working independently.

The product slogan:

**"Your development environment. Anywhere. Exactly where you left off."**

The first release must prioritize correctness, reliability, security, and practical usability over exaggerated features.

## 1. THE CORE PRODUCT

DevTeleport is a local-first workspace migration and restoration platform.

The intended experience:

On Computer A:

```bash
devteleport capture --name my-workspace
```

On Computer B:

```bash
devteleport restore ./my-workspace.dtp
```

After successful restoration, the developer should be able to continue working with:

- Project files.
- Git repository metadata.
- Uncommitted changes.
- Untracked files.
- Supported runtime dependencies.
- Relevant editor state.
- Development database contents.
- Supported Docker services.
- Development server startup configuration.
- Working-directory context.
- Selected development environment settings.

DevTeleport must distinguish between reconstructing a workspace and migrating a running process.

Do not claim to restore live process memory, open TCP connections, active debugging execution, or arbitrary unsaved application state unless that functionality is genuinely implemented and verified.
